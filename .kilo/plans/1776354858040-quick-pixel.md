# Custom AI Assistant Plan

## Overview
Create a custom AI assistant using the existing Smart-LLM-Route infrastructure with both CLI and Web interfaces.

## Architecture

```
smart_llm_route/
├── pixel_assist/         # New folder for custom AI
│   ├── __init__.py
│   ├── chat.py            # Core chat logic
│   ├── session.py         # Chat session management
│   ├── history.py         # Conversation history
│   ├── tools/             # IDE-like tools
│   │   ├── __init__.py
│   │   ├── file_reader.py # Read files from disk
│   │   ├── file_editor.py # Edit/modify files
│   │   └── executor.py    # Execute shell commands
│   ├── cli/               # CLI interface
│   │   ├── __init__.py
│   │   └── chat.py        # Interactive CLI chat
│   └── web/               # Web interface
│       ├── __init__.py
│       ├── flask_app.py   # Flask app
│       ├── fastapi_app.py # FastAPI app
│       ├── static/        # HTML/CSS/JS
│       └── templates/     # HTML templates
```

## Implementation Steps

### Phase 1: Core Chat System
1. **Create `pixel_assist/chat.py`** - Core AI chat class using SmartRouter
2. **Create `pixel_assist/session.py`** - Session management with conversation context
3. **Create `pixel_assist/history.py`** - Persist and load conversation history

### Phase 2: IDE Tools
4. **Create `pixel_assist/tools/__init__.py`** - Tool registry
5. **Create `pixel_assist/tools/file_reader.py`** - Read files from filesystem
   - `read_file(path)` - Read single file
   - `read_multiple(paths)` - Read multiple files
6. **Create `pixel_assist/tools/file_editor.py`** - Edit files
   - `edit_file(path, old, new)` - Replace text in file
   - `create_file(path, content)` - Create new file
   - `delete_file(path)` - Delete file
7. **Create `pixel_assist/tools/executor.py`** - Run shell commands
   - `execute(command, timeout)` - Run command, return output
   - `check_safety(command)` - Verify command safety

### Phase 3: Tool Integration
8. **Create `pixel_assist/tools/runner.py`** - Execute AI tool requests
   - Parse AI responses for tool calls
   - Route to appropriate tool
   - Return tool results to AI for final response

### Phase 4: CLI Interface
9. **Create `pixel_assist/cli/chat.py`** - Interactive terminal chat
   - ANSI-colored prompt
   - Command history (up/down arrows)
   - Clear screen, help commands
   - Tool commands: `/read`, `/edit`, `/run`

### Phase 5: Web Interface
10. **Create `pixel_assist/web/flask_app.py`** - Flask web server
11. **Create `pixel_assist/web/fastapi_app.py`** - FastAPI web server
    - Both have endpoints:
      - `GET /` - Chat UI
      - `POST /chat` - Send message, get response
      - `GET /history` - Load conversation history
12. **Create shared HTML/CSS/JS** - Clean chat interface

### Phase 6: Integration
13. **Update `__init__.py`** - Expose easy startup functions
14. **Add config options** - Model preference, default budget, etc.

## Features (MVP - Full IDE)

| Feature | Description |
|---------|-------------|
| Chat | Send messages, get AI responses |
| Model Selection | Choose which LLM to use |
| History | Save/load past conversations |
| Cost Tracking | Show cost per request |
| Help | List available commands |
| File Reading | Read files from filesystem |
| File Editing | Edit/modify files with AI assistance |
| Command Execution | Run shell commands safely |

## Usage

```bash
# CLI chat
python -m smart_llm_route.pixel_assist.cli.chat

# Flask Web UI
python -m smart_llm_route.pixel_assist.web.flask_app

# FastAPI Web UI
python -m smart_llm_route.pixel_assist.web.fastapi_app
```
